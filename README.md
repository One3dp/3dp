# 3D打印工作站

一言智造One3DP 的个人工作台导航：热点资讯 / 报价计算器 / 耗材管理 / 耗材资料 / 模型比赛汇总。

部署：GitHub Pages（`main` 分支根目录，无构建），站点地址 `https://one3dp.github.io/3dp/`。

## 全站视觉规范

所有页面共用 `assets/site.css` + `assets/site.js`：纸白 / 墨黑 / 一抹朱橙，直角细线、无阴影，支持深浅主题（localStorage 键 `one3dp_theme`）。

新增页面时在 `</head>` 前引入 `assets/site.css`、在 `</body>` 前引入 `assets/site.js`（子目录用 `../assets/...`），即可自动获得统一顶栏、页脚、主题切换与回到顶部。首页 `index.html` 自带完整样式，不需要引入。

## 每周趋势（`weekly-trends.html`，2026-11-08 起）

每周日更新的方向性周报，用来替代原来的每日资讯推送：**硬件趋势 5 条 + 模型趋势 5 条**，只做筛选与判断，不追求覆盖率。

- 页面结构固定四段：`01 本周硬件趋势` / `02 本周模型趋势` / `03 本周雷达` / `04 下周看点`，每个条目含「事件 + 为什么值得关注 + 来源」。
- 顶栏五字栏目名：`首页总览 / 每周趋势 / 打印工具 / 资源中心 / 社区交流`；首页 hero 快捷位编号 `03`，热点资讯行 `subs` 同步入口。
- 更新时只改三处：`page-hero` 的覆盖窗口、`.stats` 数字、各条目正文与 `footer` 的期数；不要动 `<style>` 与皮肤引用。
- 旧版每日报告（`outputs/3D打印日报-*.md`）不再新增，历史内容保留在 `history.html` 与 `archive/`。


## 每周刷新后请运行

`intl-report.html` 等页面由刷新脚本用旧模板重新生成，会丢掉统一皮肤引用（`assets/site.css` / `site.js` / favicon）、带回主标题 emoji，并把栏目名与时间口径退回旧版。刷新推送后执行一次：

```
python tools/reapply-skin.py
```

脚本幂等，可重复运行：补皮肤引用、清理主标题 emoji，并按上表统一栏目名、时间标签、标题格式与功能名。
